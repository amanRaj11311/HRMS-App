
A modular Human Resource Management System (HRMS) mobile application built using React Native with **Role-Based Access Control (RBAC)**.

---

## 🚀 Core Features

### 🔐 Role-Based Access Control (RBAC)
- Admin can assign modules to users
- Dynamic permission system:
  - Create
  - Read
  - Update (Edit)
  - Delete
  - View All
- User-specific dashboard based on permissions

## 🔄 Application Flow

1. Admin logs into the system  
2. Admin creates roles and assigns permissions (Create, Read, Update, Delete, View All)  
3. Admin assigns modules to specific users  
4. User logs in  
5. User dashboard dynamically loads only assigned modules  
6. User performs actions based on granted permissions  

➡️ Example:  
Admin → Assign Role → Assign Modules → User Login → Dynamic Dashboard
